# Platten-Werkzeug
Formatiert eine neue Platte als ext4 – nur die Platte mit der eingetragenen Seriennummer, mindestens 4 TB, nicht eingebunden, nie die Systemplatte. Kopiert danach eine Quelle (z. B. NTFS-Portable, nur lesend eingebunden) 1:1 auf die neue Platte und vergleicht Dateianzahl und Größen.
Aktion `pruefen` listet nur die Platten und verändert nichts.
